# Travel Recommendation Web Application

A responsive travel recommendation website built with HTML, CSS and JavaScript.

## Features
- Home page with introduction, navigation bar, search bar, Search and Clear buttons
- About Us page with company information and guidance for team members
- Contact Us page with contact information and an email form
- Keyword search for **beach/beaches**, **temple/temples** and **country/countries** (case-insensitive), with images, descriptions and local time

## Files
- `index.html`, `about.html`, `contact.html`
- `style.css`
- `travel_recommendation.js`
- `travel_recommendation_api.json`
